# Mall Customers EDA

## 📌 Overview

This project performs **Exploratory Data Analysis (EDA)** on the Mall Customers dataset using Python to understand customer demographics, income, and spending behavior.

## 🔍 Analysis Performed

* Data understanding and cleaning
* Gender distribution analysis
* Univariate analysis
* Outlier detection
* Bivariate analysis
* Correlation analysis
* Data visualization

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📊 Dataset

The dataset contains customer information such as:

* Customer ID
* Gender
* Age
* Annual Income
* Spending Score
